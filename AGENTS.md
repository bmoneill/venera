# AGENTS.md

## General Guidelines

- Always explain what you are going to do before writing to any files.
- Ask clarifying questions if you are unsure about any aspect of the task.
- Always write tests for new code, and ensure that all tests pass before
  considering the task complete.

## Coding Standards

- Code style: PEP 8
- Write module, class, and function docstrings.
- Use type hinting wherever possible.
- Use a heavily modular approach, create new modules for all new routes, models,
  etc.
- Use relative import paths for all internal imports.
